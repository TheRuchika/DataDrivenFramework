# Selenium Data-Driven Testing – TestNG

This project demonstrates **data-driven testing using Selenium WebDriver and TestNG**.  
It covers multiple approaches to supplying test data such as **TestNG Parameters**, **DataProviders**, and **Excel-based data sources**.

---

## 📌 Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Apache POI
- Maven
- ChromeDriver

---

## 🧪 Test Scenarios Covered
- Login testing using **TestNG @Parameters**
- Login testing using **TestNG @DataProvider**
- Login testing using **Excel-driven DataProvider**
- Validation of **successful and failed login attempts**

---

## 🧠 Key Concepts Demonstrated
- Data-driven testing
- TestNG annotations
- Parameterization via XML
- DataProviders
- Reading Excel files using Apache POI
- Assertion-based validations
